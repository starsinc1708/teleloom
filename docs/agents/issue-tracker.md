# GitHub workflow

Repository: [starsinc1708/teleloom](https://github.com/starsinc1708/teleloom).
Use Issues for bugs, workflow proposals, specs and accepted implementation tasks.
Create/assign the task before implementation; link blockers and parent specs when
applicable. Use [triage labels](triage-labels.md).

PRs are the implementation/review surface. Link the issue, describe concrete
before/after behavior and record affected checks. Keep private credentials and
chat content out of issue/PR bodies and logs. Write multiline `gh` bodies to a
UTF-8 file and pass `--body-file`.

Close a task only after its acceptance criteria are verified. Required live/human
checks stay open until performed or explicitly removed from scope by the owner;
record the decision and remaining limits. Conditional proposals stay conditional.
