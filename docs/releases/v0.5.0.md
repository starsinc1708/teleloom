# Teleloom v0.5.0 — first public release

Teleloom is a Telegram toolkit: **MCP server + portable agent skills + CLI**.
It brings scoped Telegram reading, search, sourced summaries and explicitly
confirmed actions to the agent client you choose.

This release contains 67 MCP tools and six skills, with user and bot profiles,
frozen originals, typed aggregates, compact views/excerpts, exports, digest/revision
validation, observed events and optional attachment/transcription engines.
OpenCode 2, explicit OpenCode v1, Pi, Hermes, Claude and Codex have client config targets.

## Start

Follow [English setup](../getting-started.md) or [Russian setup](../install-ru.md).
Choose [your client](../clients.md), then try an [example workflow](../workflows.md).
The Python package, module and CLI are `teleloom`; the local application and
credential namespace is `teleloom`, with `TELELOOM_*` environment variables. No PyPI publication is claimed.

Wheel and sdist are built once from the release source; `SHA256SUMS` identifies
their exact bytes. Compare package version, `build_id`, `source_commit` and
`build_type` with `teleloom doctor`; version alone is not artifact identity.

## Verification and boundaries

The release follows one source-bound full offline run, a clean-snapshot secret/
privacy scan and canonical artifact identity checks. Actual results are recorded
in [acceptance](../acceptance.md) and the repository's public release receipt.
External Telegram and model APIs are faked in automated tests. Native connection
observations predate this release and do not establish current live Telegram,
model workflow, skill-discovery or Claude Desktop GUI acceptance.

The public repository starts from a fresh root commit. Private development history,
account state, credentials and internal operational logs are not included.
